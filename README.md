# خلاصه پروژه: X Comment Translator | مترجم دیدگاه‌های X
## ساختار فایل‌ها

| فایل | نقش |
|---|---|
| `manifest.json` | تنظیمات افزونه؛ دسترسی به `x.com`/`twitter.com` و اندپوینت‌های ترجمهٔ گوگل؛ فقط مجوز `storage` |
| `background.js` | Service Worker: ارسال درخواست ترجمه به `translate.googleapis.com` (با fallback به `clients5.google.com`)، ۳ بار تلاش مجدد با backoff روی خطای 429/503، محدودسازی متن به ۱۵۰۰ کاراکتر |
| `content.js` | هستهٔ اصلی در صفحه: پیدا کردن `[data-testid="tweetText"]`، ترجمهٔ گروهی با همزمانی ۴ درخواست، کش ترجمه‌ها، تزریق ترجمه زیر متن اصلی با دکمهٔ «نمایش/پنهان کردن اصلی» |
| `content.css` | استایل بلوک ترجمه، دکمهٔ شناور (FAB) و نوار وضعیت |
| `popup.html/css/js` | پنل تنظیمات: انتخاب زبان مقصد، حالت دستی/خودکار، نمایش متن اصلی، دکمه‌های «ترجمه» و «بازگردانی» |

## ویژگی‌های کلیدی
- **دکمهٔ شناور روی صفحهٔ X**: با یک کلیک همهٔ دیدگاه‌ها ترجمه می‌شوند؛ کلیک دوباره متن اصلی را برمی‌گرداند.
- **حالت خودکار**: با `MutationObserver` توییت‌های جدید (مثلاً هنگام اسکرول) خودکار ترجمه می‌شوند؛ نودهای خود افزونه نادیده گرفته می‌شوند تا حلقهٔ بی‌نهایت رخ ندهد.
- **کش ترجمه** در حافظهٔ صفحه برای جلوگیری از درخواست تکراری.
- **تشخیص زبان**: اگر متن اصلی همان زبان مقصد باشد، ترجمه تزریق نمی‌شود.
- **RTL درست** برای فارسی، عربی، عبری، اردو و… + نام زبان به زبان خودش.
- **امنیت**: ترجمه فقط با `textContent` درج می‌شود (بدون ریسک XSS).
- رابط کاربری و پیام‌ها کاملاً **فارسی** است.

## نکات فنی
- درخواست ترجمه در background انجام می‌شود تا از CORS صفحه عبور کند (host_permissions).
- پردازش با استخر همزمانی ۴ (`pool`) و شمارندهٔ `gen` برای لغو ایمن کارهای در جریان هنگام بازگردانی.
- تنظیمات در `chrome.storage.local` ذخیره می‌شود و تغییرات بلادرنگ اعمال می‌شود.

## نصب
1. Chrome: `chrome://extensions` → Developer mode → Load unpacked → انتخاب این پوشه.
2. Firefox: از `about:debugging` → Load Temporary Add-on و انتخاب `manifest.json` (شناسهٔ gecko از قبل تعریف شده).
